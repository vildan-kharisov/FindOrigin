# PLAN.md — Поэтапный план реализации FindOrigin

## Этап 1. Инициализация проекта

- Создать проект Next.js (`npx create-next-app@latest`)
- Настроить структуру каталогов (`app/api/webhook/route.ts` и т.д.)
- Установить зависимости: `node-fetch` (если нужен), библиотека для работы с Telegram API
- Настроить переменные окружения (`.env.local`): `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY` и др.
- Проверить, что проект запускается локально

## Этап 2. Telegram Webhook

- Создать API-роут `app/api/webhook/route.ts` для приёма POST-запросов от Telegram
- Реализовать парсинг входящего `update`: извлечение `chat.id` и `text` из `update.message`
- Реализовать отправку ответа через Telegram API (`sendMessage`)
- Обеспечить быстрый ответ `200 OK` (без блокирующих операций в основном потоке)
- Протестировать локально через ngrok или аналог

## Этап 3. Обработка входных данных

- Определить тип ввода: обычный текст или ссылка на Telegram-пост
- Если ссылка — извлечь текст поста (парсинг `t.me` через embed-виджет или Telegram API)
- Если текст — использовать как есть
- Написать валидацию: пустой ввод, слишком длинный текст, некорректная ссылка

## Этап 4. Извлечение ключевых сущностей

- Отправить текст в OpenAI API (или аналогичную LLM) с промптом для извлечения:
  - ключевых утверждений
  - дат
  - чисел
  - имён
  - ссылок
- Получить структурированный ответ (JSON) с выделенными сущностями
- Сформировать на основе сущностей поисковые запросы

## Этап 5. Поиск источников

- Подключить поисковый API (Google Custom Search, Serper, Tavily или аналог)
- Выполнить поиск по сформированным запросам
- Собрать результаты: URL, заголовок, сниппет
- Отфильтровать нерелевантные результаты
- Категоризировать источники: официальные сайты, новости, блоги, исследования

## Этап 6. AI-сравнение и оценка

- Передать исходный текст и найденные источники (сниппеты) в LLM
- Попросить AI сравнить смысл (не буквальное совпадение текста)
- Получить оценку уверенности для каждого источника (0–100%)
- Отобрать 1–3 лучших совпадения

## Этап 7. Формирование и отправка ответа

- Сформировать читаемое сообщение для пользователя:
  - список источников (ссылка + краткое описание)
  - оценка уверенности для каждого
  - пояснение, если источники не найдены
- Отправить ответ через `sendMessage`
- Обработать ошибки и таймауты

## Этап 8. Деплой на Vercel

- Настроить переменные окружения в Vercel Dashboard
- Задеплоить проект (`vercel --prod` или через Git push)
- Зарегистрировать webhook в Telegram (`setWebhook` на URL Vercel)
- Провести end-to-end тестирование на продакшене

## Этап 9. Финализация

- Обработка краевых случаев (пустые сообщения, спам, ошибки API)
- Логирование ошибок
- Документация (README.md с инструкцией по запуску и деплою)
